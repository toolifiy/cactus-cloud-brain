# Cactus AI - Cloud Brain

24/7 Zero-Cost Always-On Personal Jarvis Backend.

- **FastAPI** backend with keep-alive `/health` endpoint for UptimeRobot.
- **Gemini Flash** multi-action tool router.
- **HiveMQ Cloud MQTT** encrypted TLS bridge to Windows PC & Android Phone.

## Endpoints
- `GET /health`: Healthcheck for 24/7 uptime monitoring.
- `POST /execute`: Dispatches natural language tasks to PC or Phone.
